# Thai Todo (Vite + React + Tailwind)

แอปรายการงานภาษาไทย — React 18, Vite, Tailwind CSS v4, lucide-react
ข้อมูลเก็บใน React state เท่านั้น (ไม่ใช้ localStorage)

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # สร้างไฟล์ production ใน dist/
npm run preview  # ทดลองรันไฟล์ที่ build แล้ว
```
